# Asset and reference notice

This project is an independent Android/LeviLaunchroid QoL implementation. It does not reuse the original Offhand native binary as its implementation.

The offhand-slot texture and the initial HUD layout are derived from the Offhand resource pack supplied with this project and the public `FrederoxDev/Offhand` source at https://github.com/FrederoxDev/Offhand. The repository did not declare a license when inspected for this milestone; verify permission before redistributing derivatives outside your own use. The bundled `resources/minecraft.ttf` was retained from the user-provided LeviPack asset set.

`BedrockTools` is the preferred Android native reference, and `LiteLDev/preloader-android` is used as the native mod API/build dependency. The Windows-only LeviLamina generated headers are used only as candidate layout descriptions and are not treated as verified Android ABI.
